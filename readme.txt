Единый системный паспорт для P24 Marketplace OS и безопасная семантика рубрик.

== Описание ==

Полевой мост для P24 Marketplace OS 1.0.0-alpha.3.5.1. Он добавляет машинно-читаемый контракт продукта без миграции базы:

* реестр сущностей;
* реестр маршрутов и ожидаемых ролей;
* реестр действий;
* автоматический выбор тестовых объявлений и рубрик;
* REST-паспорт /wp-json/p24-market/v1/system-map;
* отдельные значения состояния для автомобилей, одежды, недвижимости и услуг;
* подтверждение смены рубрики;
* очистка несовместимых характеристик только после явного подтверждения;
* удаление служебного слова «Главное» из публичного описания;
* карта системы в административном интерфейсе.

Патч не создаёт таблиц, не меняет платежи, PIN-вход, сообщения и авторизацию.

== Установка ==

1. Сделайте резервную копию P24 Marketplace OS и базы.
2. Установите ZIP как обычный WordPress-плагин.
3. Активируйте его рядом с P24 Marketplace OS 1.0.0-alpha.3.5.1.
4. Откройте «Шахты24 Маркет → Карта системы».
5. Выполните smoke-test из docs/SMOKE-TEST.md.

== Частые вопросы ==

= Почему это отдельный мост, а не замена ядра? =

Это безопасный полевой этап. Сначала контракт проверяется на боевом Маркете без переписывания рабочего ядра. После подтверждения код переносится внутрь следующей полной сборки P24 Marketplace OS.

= Удалятся ли старые характеристики при смене рубрики? =

Только если пользователь подтвердил смену рубрики в диалоге и затем сохранил объявление. Общие поля, цена, фотографии, контакты и текст продавца не удаляются.

= Нужны ли ручные ссылки для NOVA Web Audit? =

Нет. Аудитор может получить маршруты, роли и тестовые объекты через REST-паспорт системы.
