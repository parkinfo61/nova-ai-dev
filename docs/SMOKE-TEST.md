# Smoke Test — P24 Marketplace System Contract 1.0.0-alpha.3.5.2

## 1. Карта системы

- Открывается «Шахты24 Маркет → Карта системы».
- Показана версия ядра Маркета.
- Есть маршруты карточки, рубрики, кабинета, менеджера и разработчика.
- Кнопка JSON открывает `/wp-json/p24-market/v1/system-map`.
- В JSON нет телефонов, email и секретов.

## 2. Автоматические тестовые объекты

- Опубликованное объявление выбрано автоматически.
- Рубрика выбрана автоматически.
- Ссылки карточки, редактора и рубрики ведут на разные ожидаемые экраны.

## 3. Смена рубрики

На копии или тестовом объявлении:

1. Откройте редактор.
2. Измените «Автомобили» на «Личные вещи».
3. Должен появиться диалог с объяснением, какие данные сохранятся.
4. Нажмите «Оставить прежнюю» — рубрика должна вернуться.
5. Повторите и подтвердите смену.
6. Поле состояния должно сброситься.
7. Для одежды должны появиться понятные значения: «Новое с биркой», «Хорошее», «Есть дефекты».
8. Сохраните объявление.
9. Цена, фотографии, контакты и описание продавца должны сохраниться.
10. Автомобильные характеристики не должны выводиться в карточке одежды.

## 4. Публичная карточка

- Служебное слово «Главное» не выводится в описании.
- Для одежды значение `repair` показывается как «Есть дефекты», а не «Требует ремонта».
- Характеристики и описание визуально разделены.
- Карта, фотографии и статистика не повреждены.

## 5. Роли и маршруты

- Покупатель открывает публичную карточку.
- Продавец открывает кабинет и редактор собственного объявления.
- Менеджер открывает рабочий стол и модерацию.
- Разработчик открывает карту системы.
- NOVA Web Audit получает маршруты из системного JSON без ручного ввода.

## 6. Откат

- Деактивация моста возвращает прежнее поведение редактора.
- Объявления и рабочие таблицы остаются на месте.
