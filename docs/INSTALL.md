# Установка P24 Marketplace System Contract 1.0.0-alpha.3.5.2

1. Скачайте резервную копию действующего P24 Marketplace OS 1.0.0-alpha.3.5.1.
2. Сделайте резервную копию базы WordPress.
3. WordPress → Плагины → Добавить плагин → Загрузить плагин.
4. Установите полный ZIP этого моста и активируйте его рядом с ядром Маркета.
5. Очистите кэш сайта и браузера.
6. Откройте «Шахты24 Маркет → Карта системы».
7. Убедитесь, что определены версия ядра, тип записи объявлений, рубрика и маршруты.
8. Выполните `docs/SMOKE-TEST.md`.

## Откат

Деактивируйте и удалите мост. Его удаление не затрагивает таблицы и рабочие данные Маркета. Служебные meta `_p24msc_*` можно оставить: они не влияют на ядро и нужны только для истории семантики рубрик.
